Open a device and take notes beside it. Minimized windows stay in the task list. Unsaved notes ask before closing. Save the layout to reopen it after a refresh.

Keyboard: use each window’s Move or Resize button with arrow keys; hold Shift for larger steps. F6 switches between open windows, Shift+F6 goes back. Escape requests close.

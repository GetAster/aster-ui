Aster UI

Examples, guides and checkpoint reviews, built by bun run site. The demo runs entirely in the browser: the OData service is a WebAssembly mock with its data in IndexedDB.

The Aster demo

  • Component showcase: tile grids, advanced filtering, grouped reports and connected charts
  • Lamplight
  • Lamplight with the simulation panel: another user's edits, failed saves, slow writes
  • The mockup's moment: fresh data, clock frozen at 7 October 2026, 15:15

The library

  • Developer documentation: get started, practical guides and the searchable API reference
  • Playground: plain JavaScript against aster-ui.js and the mock, no build step
  • aster-ui.js with aster-ui.d.ts, aster-ui.css, and the themes Lamplight and Harbour (made from the theme guide alone)

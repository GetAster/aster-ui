# Security

Report a suspected vulnerability through [Report a vulnerability](https://github.com/GetAster/aster-ui/security/advisories/new), or by email to security@getaster.now. Both are private. Do not open a public issue or discussion for it.

Include the installed `@getaster/*` versions, the browser, the smallest page or steps that show the problem, and what someone could do with it. We reply in the same private report or by email.

Fixes ship as a new npm release of every `@getaster` package, recorded in [CHANGELOG.md](CHANGELOG.md). [Recover an expired session](https://ui.getaster.now/docs/guide/authentication.html) describes how the data layer handles credentials and expired sessions.
